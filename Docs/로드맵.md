# 로드맵

Project Cozy의 일정과 마일스톤을 추적합니다. 2027.2 **Steam Next Fest** (이하 *넥페*) 출전을 최우선 목표로 합니다. 프로젝트 개요는 [README.md](../README.md), 게임 디자인은 [GameDesign.md](GameDesign.md) 참조.

## 1. 타임라인 개요

- **2026.9 ~ 12**: CCL 진행 기간
- **2027.2**: 넥페 참여 (목표)

## 2. 마일스톤

- **~ 2026.6**: 1차 프로토타입
  - 기본 캐릭터 1~2개로 대강 구동되는 수준
- **~ 2026.9**: 2차 프로토타입
  - 캐릭터, 맵, 맵 꾸미기 요소
  - 상점 등 시스템까지 구동
- **~ 2026.11**: 데모 완성
  - 폴리싱 + DLC 1개 추가
- **~ 2026.12 3주차**: 빌드 안정화 → 완성
  - 넥페 데모 빌드는 사실상 12월 후반까지 완성되어야 함
- **~ 2027.1 말**: 프레스 프리뷰용 빌드 심사 제출
- **2027.2**: 넥페 본행사

## 3. 넥페 2027.2 부수 준비물

### 신청·자격
- 스팀웍스 계정 확정
- 신청 마감 일정 확인 (전년도 기준 1/13 마감, 신청 시작은 8~9월 — 실제 일정 재확인 필요)

### 페이지·마케팅
- 상점 페이지 개설
- 트레일러 / 마케팅 에셋 최신화
  - 참가 신청 마감 직후 Steam이 행사 공식 트레일러용으로 수집
- Steam 태그 설정

### 빌드
- 데모 빌드 + DLC 1개 완성
- 프레스 프리뷰용 빌드 심사 제출 (1월 말)

### 커뮤니티
- 디스코드 채널 개설

### 출시 시점
- 넥페 1주일 전까지 '출시(Live)' 상태로 전환 (조기 공개가 유입에 유리)
