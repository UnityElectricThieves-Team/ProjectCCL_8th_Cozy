# 게임 디자인

기획·디자인 결정사항과 검토 중인 항목을 추적합니다. 코어 컨셉과 코어 루프는 [README.md](../README.md), 일정·마일스톤은 [로드맵.md](로드맵.md) 참조.

## 1. 해금 매개체

- **별** (확정): 클릭 시 동물 해금. 자세한 동작은 README §2 참조.
- **피크닉 상자**: 보류. 별 외 추가 해금 매개체로 검토되었으나, 현재는 별 단일로 진행.

## 2. 아트 파이프라인 (검토 중, 미확정)

> 유정님이 작업하면서 다듬어가고 있는 영역입니다. 아래 항목은 잠정 결정 / 시도 중인 방향이며 변경될 수 있습니다.

### 이미지 파이프라인 (시도 중)

- 고화질 원본 이미지 → 픽셀화(도트화) → 유니티 삽입 흐름
- 원본 기본 크기는 256px 이내 (잠정 표준)
- 16 / 32 / 64 픽셀 청크 사이즈 테스트 후 일괄 고정 예정
- 위 프로세스가 잘 안 되면 다른 방안 모색
