Project Cozy. 컨셉 진행 축 관찰형 스토리 게임 데모

게임 방향성

동물들을 쓰다듬기와 관심으로 소녀 형태로 전환시키며, 드물게 드러나는 이상 행동과 기억 조각으로 캐릭터의 내면을 알아가는 방치형 서브컬처 수집 게임.

귀여워서 켜둔다→ 동물 수집→ 쓰다듬어 친밀도↑→ 소녀 형태 확인→ 이상 행동 발견→ 기억 조각 해금→ 애착 ↑ · 계속 켜둔다

01핵심 컨셉

전면에는 귀여운 동물 · 매력적인 소녀 · 수집 보상이 있다. 결핍과 방어기제는 이 구조를 보조하는 얇은 서사 레이어로만 작동한다. GameConceptDirection.md

🐾

1순위 · 귀여움

첫 진입 동기. 바탕화면을 돌아다니는 동물/소녀가 귀여워서 켜둔다. 어렵거나 무겁지 않게, 외형 매력이 전면에.

💗

2순위 · 애착

쓰다듬고 소녀 형태를 확인하며 정을 붙인다. 작은 결핍·희귀 이상 행동·기억 조각이 "알고 나니 더 신경 쓰인다"로 확장.

📚

3순위 · 수집욕

더 많은 소녀 형태·의상·일러스트·기억 조각을 보고 싶다. 귀여움과 애착이 누적된 결과로 강화된다.

장르 정의

  • 1차: 방치형 데스크톱 컴패니언
  • 2차: 서브컬처 캐릭터 수집형
  • 보조: 관찰형 스토리 해금 (서사는 경험을 대체하지 않는 얇은 레이어)

레퍼런스 톤: 봉제인형 정신병원(발견·이해 구조), 블루 아카이브(밝은 외형 뒤의 결핍).

타깃 & 최우선 가치

  • 메인: 서브컬처 수집형을 즐기는 20~30대 남성
  • BM: 본편 무료 + Steam DLC(의상 등)

⚡ 최적화가 곧 UX — 항상 떠 있는 게임이라 리소스 점유율이 사용자 경험을 좌우한다. 애매한 기능보다 최적화 우선.

02두 개의 진행 축

진행은 서로 다른 두 연료로 굴러간다. 신규 캐릭터를 막는 게이트는 스폰 기운, 캐릭터 성장은 친밀도. ProgressNumericBalance.md

신규 캐릭터 해금

⌨️ 스폰 기운

실제 입력 이벤트로만 누적. 키 입력·마우스 클릭당 +1 (휠 스크롤·이동은 0). idle 자동 누적 없음 — 절전·잠금·sleep 시 정지.

  • 1번째: 튜토리얼에서 스폰 포인트 10클릭
  • 2번째부터 누적 스폰 기운으로 해금
  • 10종 완주 ≈ 표준 75시간 / 고활동 30시간
캐릭터별 성장

💗 친밀도

보유한 모든 캐릭터에 개별·병렬 누적(화면 노출 무관). 세션 시간 동안 분당 +2 자동, 클릭·쓰다듬기로 각 +1 가속.

  • 소녀 전환: 친밀도 100 도달 (우클릭 토글, 2시간 후 자동 복귀)
  • 기억 조각: 단계마다 +400씩 + 카메라 촬영
  • 30분 무입력 → sleep, 누적 정지 (오프라인 파밍 아님)

패시브 분당 +2는 보유 전 캐릭터에 병렬 누적. 기억 조각 2·3은 직전 촬영 이후 새로 쌓은 +400만 보며, 촬영 시 0에서 재시작. 1,500 도달 시 골드 대신 전용 시설물 1개.

03관찰형 스토리 (선택)

외형 매력이 먼저, 내면 서사는 후속. 기억 조각 3개를 모으면 에피소드가 완성되는 얇은 보조 레이어. GameConceptDirection.md

친밀도 누적→ 소녀 형태 확인· 카메라 촬영→ 기억 조각 3개→ 에피소드→ 이후 반응 변화

소녀 형태 확인과 카메라 촬영 사이는 화살표가 아니다 — 순차 진행이 아니라, 친밀도 위에서 동시에 열리는 병렬 보상 경로이기 때문.

조작 규칙 (AILogic)

  • 짧은 좌클릭 또는 더블클릭 → Petting (친밀도 +1) (호버 상태로 마우스를 좌우로 흔드는 쓰다듬기는 이 데모엔 미구현)
  • 좌클릭 홀드 → Grab, 좌표가 포인터에 고정
  • 드롭 → Fall(느린 중력) → Landing → Idle
  • 동물 친밀도 100 + 우클릭 → 소녀 변신 / 소녀에서 우클릭 → 해제
  • 친밀도 100 도달 시 반짝임 알림(첫 호버 후엔 호버 시만), Shift+우클릭으로 반짝임 끄기/켜기
  • 고양이: 마우스가 추적 거리 안에 들어오면 일정 확률(5%)로 냥냥펀치 👊
  • 키를 뗄 때 스폰 기운 +1 (꾹 눌러도 뗄 때 1) · 공간/스폰 포인트 클릭 +1

상태 잠금 (중단 불가)

아래 액션은 재생 중 조작·다른 AI 행동으로 캔슬되지 않음(무적 판정):

Gift Drop · Transform · Wake Up · Landing

인터럽트 허용: Idle · Walk · Run · Sleep · Idle Action · Interact

UserSettings 반영: 캐릭터·공간 배율, 카운트 숨기기·자동 숨기기, 변신 금지, 마우스 추적 거리, 뷰포트 위치·크기 조절(저장 시 적용·베이스 공간 내 자유 배치·지면은 뷰포트 하단).
