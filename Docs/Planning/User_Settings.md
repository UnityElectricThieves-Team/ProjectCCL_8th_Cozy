> 이 문서는 게임의 환경 설정 창에서 유저가 직접 제어할 수 있는 모든 옵션을 정의합니다.

---

## 1. 분류 체계

환경 설정은 다음 카테고리로 그룹화합니다:

1. **창 동작 (Window Behavior)** — 게임 창이 OS와 어떻게 상호작용하는지
2. **표시 (Display)** — 화면에 무엇이 보이는지
3. **콘텐츠 제어 (Content Control)** — 어떤 콘텐츠를 노출할지
4. **시스템 (System)** — PC 환경과의 통합
5. **입력 (Input)** — 조작 방식
6. **사운드 (Sound)** — 오디오

---

## 2. 설정 항목

### 2.1 창 동작 (Window Behavior)

| 항목 | 기본값 | 설명 | 필수 |
|---|---|---|---|
| Always-on-Top | OFF | 이 게임 시스템이 다른 창들보다 무조건 앞에 있게 할 것인지 | ✅ |

#### 2.1.1 화면 설정
 
게임 창의 뷰포트(보이는 영역) 크기·위치와 각종 표시 배율을 유저가 직접 조절하는 기능. 아래 조정 항목은 모두 하나의 "화면 설정 저장" 버튼으로 함께 확정되며, 저장 전 변경은 프리뷰일 뿐 저장하지 않고 나가면 폐기된다.
 
| 항목 | 기본값 | 설명 | 필수 |
|---|---|---|---|
| 뷰포트 크기·위치 | 베이스 공간 | 너비·높이·위치 핸들로 보이는 영역 조절 |  |
| 공간 크기 (줌) | 1.0x | 인게임 전체(공간·캐릭터·시설물)의 표시 배율. 0.5x ~ 1.5x |  |
| 캐릭터 크기 | 1.0x | 캐릭터 스프라이트 자체의 크기. 0.5x ~ 1.5x |  |
| UI 크기 | 1.0x | 옵션 창, 카운트 등 UI 요소 자체의 크기. 0.5x ~ 1.5x |  |
 
> 공간 크기와 캐릭터 크기는 곱으로 합쳐진다. (예: 공간 1.5x × 캐릭터 1.5x → 캐릭터 실질 2.25x)
 
**용어**
 
| 용어 | 정의 |
|---|---|
| 마스터 캔버스 (3840 × 2160) | 모든 에셋·레이아웃의 제작 기준 절대 좌표계. 에셋은 이 위에 1:1(절대 픽셀)로 배치되며 모니터 해상도와 무관하게 크기 불변 |
| 베이스 공간 | 해당 모니터에서 시설물·캐릭터를 배치할 수 있는 전체 바탕 공간. 항상 모니터 해상도와 같은 크기이며 마스터 캔버스를 잘라낸 일부. 이때, 마스터 캔버스의 **우측 하단**을 기준으로 잘라 남긴다. 예: 1920 × 1080 모니터 → 4K 캔버스의 우하단 1920 × 1080 영역만 베이스 공간으로 사용. 참고로, 유저가 더 작은 모니터로 접속해 베이스 공간이 줄어들면, 잘려서 베이스 공간 밖에 놓이게 된 시설물은 모두 인벤토리로 회수된다. |
| 뷰포트 | 베이스 공간 중 실제로 화면에 보이는 영역. 위치·크기 조절의 대상으로, 베이스 공간 안 어디로든(상단 좌/우 포함) 옮길 수 있으나 베이스 공간 밖으로는 나갈 수 없다. 너비·높이·위치를 각각 핸들로 조절한다. **땅바닥(캐릭터가 서는 지면)은 항상 뷰포트 하단 변에 포함되며 뷰포트와 함께 이동한다.** |
 
**제약**
 
- 최소 크기: 720 × 480 (절대 픽셀) 까지만 축소 가능
- 최대 크기: 베이스 공간 (모니터 해상도)
- 위치·크기는 베이스 공간 안에서 자유롭게 조절한다. 높이는 상단(천장) 핸들과 하단(지면) 핸들로 각각 조절하며, 상단 핸들은 천장을, 하단 핸들은 지면을 움직인다. 지면은 항상 뷰포트 하단에 있으므로, 뷰포트를 위로 옮기거나 하단 핸들을 올리면 지면도 함께 따라온다.

**캐릭터·시설물 처리 (조정 중 · 저장 시)**
 
- 조정 중: 캐릭터·시설물은 그대로 존재하며, 뷰포트 밖으로 나간 대상도 사라지지 않는다. 리사이징·줌·캐릭터 크기를 조절하는 동안 현재 뷰포트 경계를 기준으로 회수 예정 대상이 실시간으로 갱신된다. 기본(권장) 시각화 방식은 뷰포트 경계 바깥 영역 전체를 반투명 처리하고, 그중 회수 예정 대상에만 빨간 외곽선을 입히는 것이다(경계가 바뀔 때마다 실시간 반영). 구현이 어려울 경우 대안으로 저장 시 "시설물 N개가 회수됩니다. 진행할까요?" 확인을 띄운다.
- 저장 시: 모든 조정(리사이징·줌·캐릭터 크기)이 한 번에 적용된다. 시설물의 경우 뷰포트 안에 온전히 들어온 것만 자리에 유지되고, 조금이라도 걸치거나 벗어난 것은 모두 인벤토리로 회수된다. 캐릭터는 조금이라도 이탈하면 "펑" 연출과 함께 뷰포트 내 랜덤 위치로 재스폰되며, 이때 캐릭터끼리 겹쳐서 리스폰되어도 무방하다.

### 2.2 표시 (Display)

**기타 표시**

| 항목 | 기본값 | 설명 | 필수 |
|---|---|---|---|
| Spawner 카운트 숨기기 | ON | 스폰되는 곳의 누적 카운트 숨김 |  |
| 캐릭터 카운트 숨기기 | ON | 각 캐릭터의 친밀도 카운트 숨김 — 이 기능 할지 말지 고민중, 협의 예정 |  |
| 카운트 자동 숨기기 | ON | 마우스 커서가 스프라이트 위에 없으면 카운트 자동 숨김 (호버 시에만 표시) |  |

**카운트 숨기기 로직:**

| Spawner/캐릭터 카운트 숨기기 | 자동 숨기기 | 결과 |
|---|---|---|
| ON | ON | 평소엔 안 보임 → 마우스 커서 호버 시에만 표시 |
| ON | OFF | 자동 숨기기와 상관없이 항상 안 보임 (앨범 등에서만 확인) |
| OFF | (무관) | 자동 숨기기와 상관없이 항상 보임 |

> Spawner·캐릭터 카운트 숨기기가 **모두 OFF**면 숨길 대상이 없어 자동 숨기기가 무의미하므로, 자동 숨기기 옵션은 OFF로 고정·비활성화한다.
