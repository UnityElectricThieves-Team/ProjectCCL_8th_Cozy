# 유저 환경 설정 (User Settings)

## 변경 이력
- 260525: 초안 작성
- 260603: 관리자 모드 항목 추가

---

> 이 문서는 게임의 환경 설정 창에서 유저가 직접 제어할 수 있는 모든 옵션을 정의합니다.

---

## 1. 분류 체계

환경 설정은 다음 카테고리로 그룹화합니다:

1. **창 동작 (Window Behavior)** — 게임 창이 OS와 어떻게 상호작용하는지
2. **표시 (Display)** — 화면에 무엇이 보이는지
3. **콘텐츠 제어 (Content Control)** — 어떤 콘텐츠를 노출할지
4. **시스템 (System)** — PC 환경과의 통합
5. **입력 (Input)** — 조작 방식
6. **사운드 (Sound)** — 오디오

---

## 2. 설정 항목

### 2.1 창 동작 (Window Behavior)

| 항목 | 기본값 | 설명 | 필수 |
|---|---|---|---|
| Always-on-Top | OFF | 이 게임 시스템이 다른 창들보다 무조건 앞에 있게 할 것인지 | ✅ |
| 주 디스플레이 설정 | 1 | 다중 모니터 환경에서 캐릭터를 표시할 모니터 선택 (오직 한 모니터에만 표시) | ✅ |

### 2.2 표시 (Display)

| 항목 | 기본값 | 설명 | 필수 |
|---|---|---|---|
| 캐릭터 크기 | 1.0x | 0.5x ~ 2.0x 범위 (논의 필요) |  |
| UI 크기 | 1.0x | 옵션 창, 카운트 등 UI 요소의 크기 |  |
| Spawner 카운트 숨기기 | ON | 스폰되는 곳의 누적 카운트 숨김 |  |
| 캐릭터 카운트 숨기기 | ON | 각 캐릭터의 친밀도 카운트 숨김 — 이 기능 할지 말지 고민중, 협의 예정 |  |
| 카운트 자동 숨기기 | ON | 마우스 커서가 스프라이트 위에 없으면 카운트 자동 숨김 (호버 시에만 표시) |  |

**카운트 숨기기 로직:**

| Spawner/캐릭터 카운트 숨기기 | 자동 숨기기 | 결과 |
|---|---|---|
| ON | ON | 평소엔 안 보임 → 마우스 커서 호버 시에만 표시 |
| ON | OFF | 자동 숨기기와 상관없이 항상 안 보임 (앨범 등에서만 확인) |
| OFF | (무관) | 자동 숨기기와 상관없이 항상 보임 |

### 2.3 콘텐츠 제어 (Content Control)

| 항목 | 기본값 | 설명 | 필수 |
|---|---|---|---|
| 미소녀 변신 금지 | OFF | ON 시 변신 시스템 자체 비활성화 |  |
| 등장 캐릭터 선택 | (전체) | 환경설정 창이 아닌 앨범 등에서 체크 형태로 관리 — 화면에 등장시킬 캐릭터 개별 선택 |  |

### 2.4 시스템 (System)

| 항목 | 기본값 | 설명 | 필수 |
|---|---|---|---|
| 자동 실행 | OFF | PC 부팅 시 자동 실행 | ✅ |
| 관리자 모드 | OFF | ON 시 다른 앱 사용 중 발생한 키보드·마우스 입력도 스폰 기운으로 카운트 |  |
| 방해 금지 모드 (Boss Key) | F2 (단축키 할당 가능, 어려우면 F2 고정) | 단축키 입력 시 모든 캐릭터 즉시 숨김 |  |
| 데이터 백업/복원 | ON | 클라우드 또는 파일로 저장 (PC 포맷 시 보호) |  |
| 초기화 옵션 | - | 특정 캐릭터 친밀도 리셋, 전체 리셋 (확인 절차 필수) |  |

### 2.5 입력 (Input)

| 항목 | 기본값 | 설명 | 필수 |
|---|---|---|---|
| 컨트롤러 지원 | OFF | 가장 후순위로 검토 문의 |  |
| 마우스 추적 거리 | (기본값 미정) | 캐릭터가 마우스에 반응하는 거리 조정 |  |

### 2.6 사운드 (Sound)

| 항목 | 기본값 | 설명 | 필수 |
|---|---|---|---|
| 전체 볼륨 | 100% | |  |
| 캐릭터 효과음 | 100% | 각 캐릭터의 울음/소리 |  |
| UI 효과음 | 100% | 클릭, 변신 등 |  |
