### 🎬 폼(Form)별 캐릭터 애니메이션 상세 리스트

#### 1. 🐾 동물 폼 (Animal Form) 

| 액션명 (State) | 상세 설명 (동작 컨셉) |
| :--- | :--- |
| **Spawn (등장)** | 해금 시 별(가제)에서 '툭' 떨어져서 착지하는 모션 |
| **Idle (대기)** | 앉아서 꼬리를 살랑이거나 가만히 응시하는 기본 모션 |
| **Sleep (취침)** | 몸을 둥글게 말거나 엎드려 잠든 모션 |
| **Walk (이동)** | 발로 화면을 뽈뽈뽈 걸어 다니는 모션 |
| **Grabbed (잡힘)** | 마우스로 클릭해서 들어 올렸을 때, 뒷덜미가 잡힌 채 대롱대롱 바둥거리는 귀여운 모션 |
| **Petting (쓰담쓰담)** | 마우스로 클릭하거나 휘저었을 때 기분 좋아하며 하트를 띄우는 반응 |
| **Transform (변신)** | 소녀로 전환될 때 빛이나 연기(펑!) 파티클로 가려지는 이펙트용 소스 |

---

#### 2. ✨ 소녀 폼 (Girl Form) 

| 액션명 (State) | 상세 설명 (동작 컨셉) |
| :--- | :--- |
| **Idle (대기)** | 두 발로 서서 가볍게 숨을 쉬고 가만히 응시하는 기본 모션 |
| **Sleep (취침)** | 앉아서 꾸벅꾸벅 졸거나, 바닥에 엎드려 평온하게 자는 모션 |
| **Walk (이동)** | 두 발로 화면을 총총총 걸어 다니는 모션 |
| **Petting (쓰담쓰담)** | 마우스로 쓰다듬으면 부끄러워하거나 환하게 웃는 모션 |
| **Gift Drop (선물 툭)** | 품에서 선물을 꺼내어 바닥에 툭 떨어뜨리는 모션 |
| **Grabbed (잡힘) - 선택** | 마우스로 클릭해서 들어 올렸을 때, 대롱대롱 바둥거리는 귀여운 모션 |
| **Transform (변신)** | 다시 동물로 전환(해제)될 때 빛이나 연기(펑!) 파티클로 가려지는 이펙트용 소스 |
