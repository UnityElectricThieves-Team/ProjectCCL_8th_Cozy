### 🎬 폼(Form)별 캐릭터 애니메이션 상세 리스트

#### 1. 🐾 동물 폼

| 액션명 | 상세 설명 (동작 컨셉) | 비고 |
| :--- | :--- | :--- |
| **Idle (대기)** | 앉아서 꼬리를 살랑이거나 가만히 응시하는 기본 반복 모션 | - |
| **Idle Action (특수 대기)** | 제자리에서 하품하기, 기지개 켜기, 털 고르기 등 일회성 포인트 동작 | - |
| **Sleep (취침)** | 몸을 둥글게 말거나 엎드려 잠든 모션 | - |
| **Wake Up (기상)** | 부스스 눈을 비비거나 고개를 터는 등 일어나는 모션 | - |
| **Walk (이동)** | 네 발로 화면을 뽈뽈뽈 걸어 다니는 모션 | - |
| **Run (달리기)** | 기본 Walk보다 빠르게 뛰어가는 모션 | - |
| **Petting (쓰담)** | 마우스로 휘둘러 쓰다듬을 시 기분 좋아하며 웃는 모션 | - |
| **Grabbed (잡힘)** | 마우스 클릭으로 들어 올릴 시, 대롱대롱 바둥거리는 모션 | - |
| **Fall (낙하)** | 클릭 해제 시 바닥을 향해 떨어지며 허우적거리는 체공 모션 | - |
| **Spawn (착지)** | 등장 시 혹은 Fall 이후 바닥에 안착하는 모션 | - |
| **Transform (변신)** | 소녀로 전환될 때 빛이나 연기 파티클로 가려지는 효과용 소스 | - |
| **Sit (앉기)** | 작업표시줄이나 창 테두리에 얌전히 앉아 있는 모션 | 구현 어려움, 패스 |
| **Consume (먹기)** | 상점에서 산 아이템(물약 등)을 오물오물 먹는 모션 | 인게임 아이템 없을 시 제작 안 함 |
| **Interact (상호작용)** | 마우스나 시설물 등 특정 타겟과 상호작용하는 액션 | 캐릭터별 상세 리스트 참조 |

#### 2. ✨ 소녀 폼 (Girl Form)

| 액션명 (State) | 상세 설명 (동작 컨셉) | 비고 (Remarks) |
| :--- | :--- | :--- |
| **Idle (대기)** | 두 발로 서서 가볍게 숨을 쉬고 가만히 응시하는 기본 모션 | - |
| **Idle Action (특수 대기)** | 옷매무새 다듬기, 기지개 켜기 등 일회성 포인트 동작 | - |
| **Sleep (취침)** | 앉아서 꾸벅꾸벅 졸거나 바닥에 엎드려 자는 모션 | - |
| **Wake Up (기상)** | 눈을 비비적거리며 몽롱하게 깨어나는 모션 | - |
| **Walk (이동)** | 두 발로 화면을 총총총 걸어 다니는 모션 | - |
| **Run (달리기)** | 기본 Walk보다 빠르게 뛰어가는 모션 | - |
| **Petting (쓰담)** | 마우스로 쓰다듬으면 부끄러워하거나 환하게 웃는 모션 | - |
| **Grabbed (잡힘)** | 마우스로 들어 올릴 시, 당황하며 대롱대롱 바둥거리는 모션 | - |
| **Fall (낙하)** | 바닥을 향해 떨어지며 치마를 부여잡거나 허우적거리는 모션 | - |
| **Spawn (착지)** | Fall 이후 바닥에 안착하는 모션 | - |
| **Gift Drop (선물)** | 품에서 선물을 꺼내어 바닥에 툭 떨어뜨리는 모션 | - |
| **Transform (변신)** | 다시 동물로 전환될 때 파티클로 가려지는 효과용 소스 | - |
| **Surprised / Annoyed** | 귀찮게 했을 때 놀라거나 짜증내는 모션 | 제작 여부 고민 중 |
| **Sit (앉기)** | 작업표시줄이나 창 테두리에 다리를 내리고 앉아 있는 모션 | 구현 어려움, 패스 |
| **Consume (먹기)** | 상점에서 산 아이템(물약 등)을 오물오물 먹는 모션 | 인게임 아이템 없을 시 수행 안 함 |
| **Interact (상호작용)** | 특정 오브젝트와 상호작용할 때 짓는 제스처 | 캐릭터별 상세 리스트 참조 |

### 🐾 캐릭터별 특수 상호작용 목록

각 캐릭터(동물/소녀)마다 고유하게 수행하는 `Interact` 액션들입니다.

| 캐릭터명 | 폼 (Form) | 액션 이름 | 상세 동작 내용 | 필요 오브젝트 / 타겟 |
| :--- | :--- | :--- | :--- | :--- |
| **흑고양이** | 동물 | 냥냥펀치 | 앞발을 빠르게 뻗어 대상을 통통 침 | 마우스 커서 |
| **흑고양이** | 동물 | 꾹꾹이 | 대상을 향해 양발을 교대로 누름 | 무릎(유저 가상 인식) |
| **강아지** | 동물 | 배 뒤집기 | 바닥에 누워 배를 보여주며 꼬리를 흔듬 | 유저 클릭(쓰담 유도) |
