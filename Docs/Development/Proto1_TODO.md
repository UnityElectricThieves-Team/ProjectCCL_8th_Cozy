## 캐릭터 AI

- [ ] `Idle` — 기본 대기, 일정 시간 후 Walk 전환
- [ ] `Idle Action` — 하품/기지개 등 일회성 특수 대기 *(선택)*
- [ ] `Walk` — 화면 내 랜덤 좌표 이동, 도착 시 Idle 복귀
- [ ] `Run` — Walk보다 빠른 달리기
- [ ] `Sleep` — X분 OS 입력 없으면 수면 진입
- [ ] `Wake Up` — 재입력 감지 시 기상 모션 후 Idle 복귀
- [ ] 화면 경계 처리 — 모니터 밖으로 나가지 않도록
- [ ] 바닥 기준선 설정 — 작업표시줄 상단 기준 착지 판정
