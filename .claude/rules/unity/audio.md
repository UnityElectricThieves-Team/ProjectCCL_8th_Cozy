# 오디오 규약

배경음악을 어디에 두고 어떻게 들고 있는지에 대한 규칙입니다. 효과음은 아직 없습니다.

## 음원은 Assets에 두고, StreamingAssets에 두지 않습니다

두 곳 모두 빌드에 담겨 모든 사용자에게 똑같이 배포됩니다. 차이는 Unity가 파일을 가공하느냐입니다.

- **StreamingAssets**는 원본 파일을 빌드 폴더에 그대로 복사합니다. Unity의 압축·스트리밍 임포트 설정을 받지 못하고, 실행 중에 경로로 직접 읽어야 하며, 게임 폴더에 원본 음원이 그대로 놓여 누구나 복사해 갈 수 있습니다. 음원을 따로 판매할 가능성과도 맞지 않습니다.
- 도감 데이터가 StreamingAssets에 있는 이유는 Unity 밖의 WPF 툴이 만드는 파일이기 때문입니다. 음원은 Unity 안에서 다루는 에셋이라 해당하지 않습니다.

## 배경음악은 `Assets/Audio/BGM/`에 넣습니다

오디오 팀이 파일을 넣는 자리입니다. 이 폴더에 새로 들어온 파일에는 Preset Manager가 `BgmImport.preset`을 자동으로 적용합니다(Load Type **Streaming**, **Vorbis** 압축).

- **Streaming인 이유**: 곡 전체를 메모리에 풀어 두지 않고 재생하면서 조금씩 읽습니다. 몇 분짜리 곡을 통째로 풀면 수십 MB가 상주하는데, 이 게임은 바탕화면에 항상 떠 있어 상주 메모리가 곧 사용자 경험입니다.
- 코드(AssetPostprocessor)가 아니라 Preset을 쓴 것은 Unity 기본 기능으로 같은 일을 할 수 있기 때문입니다. Preset은 처음 임포트할 때만 적용되므로, 나중에 인스펙터에서 손으로 바꾼 값은 덮어쓰지 않습니다.
- 다른 폴더에 넣으면 Preset이 걸리지 않아 Unity 기본값(곡 전체를 풀어 둠)으로 임포트됩니다.

## 곡 목록은 `BgmCatalog` 하나입니다

- 첫 곡이 기본 곡입니다. 곡마다 에셋을 나누지 않은 것은 순서를 한 곳에서 보이게 하려는 것입니다.
- 곡은 파일 경로가 아니라 AudioClip을 직접 참조합니다. 경로 문자열은 파일을 옮기거나 이름을 바꾸면 조용히 끊깁니다.
- 곡 `id`는 설정 파일에 저장되므로 한번 정하면 바꾸지 않습니다. 저장된 id가 목록에 없으면 첫 곡으로 돌아가며, 이 판단은 `BgmCatalog` 한 곳에서만 합니다.

## 드롭다운의 곡 이름도 `BgmCatalog`에서 가져옵니다

설정 패널 배경음악 드롭다운의 옵션은 시작할 때 코드가 곡 목록의 순서와 `displayName`으로 만듭니다. 프리팹 드롭다운의 Options는 덮어써지므로 손대지 않습니다.

- **이름과 곡을 한 곳(곡 목록의 한 줄)에 두는 이유:** 드롭다운 옵션에는 글자·그림·색만 들어가고 곡을 이어 줄 칸이 없어, 따로 적으면 순서로만 대응합니다. 그러면 순서가 어긋났을 때 고른 이름과 나오는 곡이 달라지고, 코드는 그걸 알아챌 수 없습니다. 드롭다운 Options에 직접 적는 방식을 한 번 썼다가 이 이유로 되돌렸습니다(2026-10-04).
- **곡 이름은 번역하지 않습니다.** 화면 글자는 키로 찾아 쓴다는 [localization.md](localization.md) 원칙의 예외입니다. 곡 제목은 고유명사라 언어마다 바꿀 필요가 적고, 곡을 추가할 때 고칠 곳이 곡 목록 하나로 끝납니다.
- 곡 이름이 번역 대상이 아니므로, 언어가 바뀌어도 옵션을 다시 만들지 않습니다. 다시 만들면 `ClearOptions`가 알림 없이 선택을 첫 곡으로 돌려 저장값과 화면이 갈라집니다.
- 설정 파일에는 드롭다운 순서 번호가 아니라 곡 id를 저장합니다. 이유는 언어를 태그로 저장하는 것과 같습니다([localization.md](localization.md)).

## 볼륨은 AudioMixer로 조절합니다

- 그룹은 `Master` 아래 `Music`과 `SFX`입니다. 배경음악 재생기는 `Music`으로 출력하고, 효과음이 생기면 `SFX`로 출력합니다. 소리 내는 쪽이 몇 개든 슬라이더는 그룹 볼륨 하나만 바꿉니다.
- 슬라이더 값 0~1은 데시벨로 바꿔 믹서의 노출 파라미터에 넣습니다. 값을 그대로 넣으면 귀에 들리는 크기가 고르게 변하지 않습니다. 파라미터 이름은 코드 상수와 믹서 에셋이 글자까지 같아야 하고, 틀리면 경고가 한 번 뜹니다.
- `AudioMixer.SetFloat`는 `Awake`에서 부르면 무시되므로 첫 반영은 `Start`에서 합니다.
- 음소거는 볼륨과 따로 저장하고, 음소거 중에는 Master만 최저로 내립니다. 그래야 풀었을 때 원래 볼륨으로 돌아옵니다.

## 볼륨만은 손을 뗄 때 저장합니다

설정은 바뀔 때마다 즉시 저장하는 것이 원칙인데, 슬라이더는 끄는 동안 매 프레임 값을 보내 매 프레임 파일을 쓰게 됩니다. 그래서 볼륨은 소리에는 바로 반영하고, 파일 저장은 슬라이더에서 손을 뗄 때 합니다.

- 같은 이유로 볼륨은 설정 공용 이벤트 대신 볼륨 전용 이벤트를 울립니다. 공용 이벤트의 구독자(캐릭터 설정 적용, 설정 화면 전체 갱신 등)는 가끔 울리는 이벤트를 전제로 만들어졌습니다.
- 손 뗌이 Unity에 오지 않는 경우가 실제로 있습니다. 드래그 중 커서가 투명 영역으로 나가면 클릭 통과가 켜져 뗌이 바탕화면으로 가고, 키보드로 조작해도 손 뗌이 없습니다. 이때는 종료할 때, 또는 다른 설정이 저장될 때 함께 기록됩니다. 강제 종료하면 마지막 드래그 값만 잃는데, 이 정도는 감수합니다.
- 패널이 닫힐 때 저장하지 않는 이유: 패널은 CanvasGroup으로 숨기기만 해서 닫힘을 알 지점이 없습니다.
