# Figma 기획 읽는 법

기획의 정답은 Figma에 있습니다 (루트 [CLAUDE.md](../../CLAUDE.md) §1). 이 문서는 *왜 Figma가 정본인지*가 아니라, **그걸 어떤 도구로 어떻게 읽는지**만 다룹니다.

## 대상 파일

- 파일 이름: `CCL_8th_Cozy_Companion`
- 파일 키: `Ga2XVMMDeOYEv6YHMGLxiR`
- URL: https://www.figma.com/design/Ga2XVMMDeOYEv6YHMGLxiR

페이지는 `Page 1` 하나뿐이고, 화면 단위 기획이 최상위 프레임으로 나란히 놓여 있습니다 (메인, 상점, 인벤토리, 도감, 사진첩, 옵션, 각종 팝업 등). 그래서 "어느 페이지에 있나"를 찾을 필요는 없고, **어느 프레임인지**만 찾으면 됩니다.

## 기본은 브라우저입니다

**Figma는 사용자가 켜둔 브라우저를 통해 봅니다.** 도구는 `mcp__claude-in-chrome__*`입니다. 사용자가 실제로 쓰는 Edge를 그대로 조종하므로, 사용자가 보고 있는 것과 같은 것을 봅니다.

**Figma MCP는 쓰지 않습니다.** Figma 접근은 이 브라우저 경로 하나뿐입니다. 사용자가 명시적으로 요청해도 먼저 브라우저로 해결할 수 있는지 봅니다.

### 브라우저로 읽는 순서

1. `tabs_create_mcp`로 새 탭을 엽니다. 사용자가 보고 있던 탭을 빼앗지 않습니다.
2. `navigate`로 파일을 엽니다. 특정 프레임으로 바로 가려면 URL에 `?node-id=`를 붙입니다. **이때 콜론이 하이픈으로 바뀝니다** — 노드 `8:36`은 `?node-id=8-36`입니다.
3. 프레임 목록이 필요하면 좌측 레이어 트리를 `read_page`로 읽습니다. 캔버스와 달리 레이어 트리는 진짜 DOM이라 이름이 그대로 나옵니다.
4. 캔버스 내용은 `computer`의 스크린샷으로 봅니다. 글씨가 작으면 `zoom` 액션으로 영역을 잘라 확대합니다. Figma 단축키도 씁니다 — `Shift+2`는 선택한 프레임에 맞춰 확대, `Shift+1`은 전체 보기입니다.
5. 수치나 색상이 필요하면 그 오브젝트를 클릭해 선택하고 우측 속성 패널을 읽습니다 (아래 "수치와 색상" 참고).
6. 다 봤으면 `tabs_close_mcp`로 탭을 닫습니다.

**로딩이 끝나기 전에 `read_page`나 `find`를 부르면 선택 이전 상태가 잡힙니다.** `?node-id=`로 들어가도 파일이 다 뜨기까지 잠깐 걸려서, 그 사이에 패널을 읽으면 오브젝트 속성 대신 페이지 속성이 나옵니다. 먼저 스크린샷으로 원하는 것이 선택됐는지 확인하고 읽습니다.

여러 동작은 `browser_batch`로 묶으면 왕복이 줄어 빠릅니다. 단 `browser_batch`는 `mcp__claude-in-chrome__` 쪽 것을 써야 합니다.

### 브라우저에서 걸리는 함정

**반드시 `mcp__claude-in-chrome__*`입니다.** 이 세션에는 브라우저 도구가 세 벌 있고 기본값은 앱 내장 브라우저(`mcp__Claude_Browser__*`)인데, 내장 브라우저와 playwright에는 Figma 로그인 세션이 없어서 파일이 열리지 않습니다. 로그인된 브라우저는 사용자의 Edge 하나뿐입니다.

**캔버스는 WebGL이라 DOM으로 안 읽힙니다.** `read_page`를 불러도 캔버스 안의 기획 문구는 나오지 않습니다. 나오는 것은 레이어 트리, 우측 속성 패널, 댓글 영역, 툴바뿐입니다. 캔버스 안은 반드시 스크린샷으로 봅니다. (Figma에 캔버스를 접근성 트리에 노출하는 스크린 리더 설정이 있고 `Ctrl+K`로 켤 수 있지만 기본은 꺼져 있습니다.)

**`read_page`를 그냥 부르면 레이어 트리가 통째로 딸려와 3만 자에 가깝습니다.** `ref_id`나 `filter: "interactive"`로 좁혀서 부릅니다.

**스크린샷의 글꼴은 원본과 다를 수 있습니다.** 이 파일은 DOSPilgi, 메이플스토리 같은 글꼴을 쓰는데 브라우저에 그 글꼴이 없으면 Figma가 "누락된 글꼴" 경고를 띄우고 대체 글꼴로 그립니다. 레이아웃을 보는 데는 문제없지만 **글꼴이나 자간을 판단 근거로 삼지는 마세요.**

### 수치와 색상은 우측 패널에서 정확히 읽습니다

**캔버스에서 눈대중하지 말고, 오브젝트를 선택해 우측 속성 패널의 값을 읽습니다.** 캔버스는 그림이라 픽셀을 세는 게 의미가 없지만, 패널에는 확정된 숫자가 그대로 적혀 있습니다.

- **크기·위치·회전**은 접근성 트리에 라벨만 있고 값이 없습니다 (`textbox "너비"`처럼 나옵니다). 그래서 `zoom`으로 패널 영역을 잘라 확대해서 읽습니다. 큼직한 UI 숫자라 또렷하게 읽힙니다.
- **색상 hex는 확대할 필요도 없습니다.** 접근성 트리에 `button "단색 hex: FFFFFF"` 형태로 텍스트가 들어 있어 `read_page`로 바로 잡힙니다.
- 불투명도·모서리 반경처럼 라벨이 따로 없는 항목도 `textbox "100%"`, `textbox "0"`처럼 값이 그대로 나옵니다.

한계는 하나입니다. **이 방법은 오브젝트를 하나씩 선택해야 합니다.** 수십 개의 수치가 필요하면 시간이 걸리니, 정말 필요한 오브젝트만 고릅니다. 화면 전체의 모양이 필요할 뿐이면 프레임 스크린샷 한 장으로 충분한지 먼저 봅니다.

## 브라우저로만 되는 일

다음은 캔버스 안에서만 확인할 수 있어서 브라우저로 해야 합니다.

- **프로토타입 클릭.** 기획 문구에 "'프리뷰'로 해놓고 버튼 클릭해보세요" 같은 지시가 여러 군데 있습니다. 버튼이 어디로 이어지는지는 프리뷰를 직접 눌러 봐야 압니다.
- **Figma 댓글.** 우측 댓글 영역이나 댓글 모드에서 읽습니다.
- **아트 리소스 내려받기.** 오브젝트를 선택하고 우측 패널 아래의 Export로 받습니다. 파일을 받는 일이라 그때마다 사용자에게 파일 이름과 위치를 말하고 허락을 구합니다. 받은 파일을 둘 폴더는 Unity 프로젝트의 기존 `*_from_figma` 폴더 중에서 사용자가 정해 줍니다.

브라우저가 연결되어 있지 않으면 다른 경로로 우회하지 말고, 사용자에게 확장 상태를 확인해 달라고 말합니다. 사용자에게 Figma 화면 캡처를 부탁하는 것도 방법입니다.

## 최초 1회 준비

1. Edge에 Claude for Chrome 확장을 설치하고 로그인합니다. Edge는 Chromium 계열이라 Chrome 웹 스토어 확장이 그대로 설치됩니다.
2. 그 브라우저에서 Figma에 로그인해 둡니다. 확장은 브라우저의 로그인 세션을 그대로 씁니다.
3. `list_connected_browsers`가 빈 배열이 아니면 연결된 겁니다. 여러 개면 `select_browser`로 고릅니다. 확장이 사이트 접근을 막으면 그때 확장 UI에서 `figma.com`을 허용합니다.
